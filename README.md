# petsitting-privacy

Hébergement statique de la politique de confidentialité de l'app Android **Truffy** (pet-sitting), requise par Google Play Console.

URL publique : https://asueg.github.io/petsitting-privacy/ (français)
Version anglaise : https://asueg.github.io/petsitting-privacy/en.html

L'app est bilingue et sa locale par défaut est l'anglais, donc chaque fiche Play pointe vers la page de sa langue. **Toute modification de fond se fait dans les deux fichiers** : une seule page à jour est un engagement faux vis-à-vis des utilisateurs de l'autre langue.

Le repo principal de l'app est privé ; cette page est volontairement isolée pour ne pas exposer le code.
